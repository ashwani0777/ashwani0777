## 🚀 Featured project

**[Serverless Image Resizer on AWS](https://github.com/ashwani0777/Image-Resizing-project-on-aws)**
An event-driven pipeline built with Terraform. An S3 upload triggers a Python Lambda (Pillow) that writes thumbnails to a second encrypted bucket and sends an SNS email. It uses least-privilege IAM, encrypted private buckets, pytest/moto tests, and a GitHub Actions workflow that runs tests and `terraform fmt/validate` on every push.
