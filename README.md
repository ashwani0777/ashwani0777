## 🚀 Featured Project

**[Serverless Image Resizer on AWS (Terraform)](https://github.com/ashwani0777/Image-Resizing-project-on-aws)**

Upload an image to S3, a Lambda function resizes it, the thumbnail lands in a second bucket, and an SNS email reports the result. Everything is provisioned with Terraform.

- Python 3.12 Lambda with a Pillow layer; keeps aspect ratio, fixes phone-photo rotation, never upscales
- Private, encrypted S3 buckets with public access blocked
- Least-privilege IAM and 14-day CloudWatch log retention
- Unit tests with pytest and moto, plus a GitHub Actions workflow running tests and `terraform fmt` / `validate` on every push
