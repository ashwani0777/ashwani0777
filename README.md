## Featured Project

**[Serverless Image Resizer on AWS](https://github.com/ashwani0777/Image-Resizing-project-on-aws)**

Event-driven image-processing pipeline provisioned with Terraform. An S3 upload triggers a Python Lambda (Pillow) that writes thumbnails to a second encrypted bucket and sends an SNS email notification. Includes least-privilege IAM, private encrypted buckets, pytest/moto unit tests, and a GitHub Actions workflow that runs tests and `terraform fmt` / `validate` on every push.
